# 家庭营养膳食规划系统

基于《中国居民膳食营养素参考摄入量》与多维约束求解的家庭每日 / 每周配餐工具。输入家庭成员画像、预算与忌口，输出满足热量、宏量营养素供能比、微量营养素达标、预算上限、过敏原规避与食材轮换要求的完整膳食方案。

## 快速开始

```bash
npm install
npm run dev
```

启动后自动选择空闲端口并打开浏览器。仅依赖 Node.js 原生模块，无需任何第三方包，macOS / Windows / Linux 均可运行。

## 功能特性

- **膳食参考摄入量（RNI）计算**：按年龄分层、性别、活动水平（轻 / 中 / 重体力）与膳食目标（维持 / 减重 / 增肌）动态计算每日能量与 9 类营养素需求，钠按上限约束。
- **单日多维约束求解**：在固定三餐模板（早：主食+蛋奶+水果；午 / 晚：主食+蛋白主菜+两蔬+油脂；加餐坚果）基础上，迭代调整克重与食材，同时满足：
  - 热量落在目标 ±5% 区间
  - 宏量营养素供能比：脂肪 20-30%、蛋白质 10-20%、碳水 50-65%
  - 微量营养素达标度与钠上限
  - 每日预算上限（超限时优先在同类食材内替换更廉价选项，其次压缩克重）
  - 过敏原规避与指定食材排除
- **周菜单生成**：7 天 × 三餐整体编排，保证：
  - 午餐蛋白质来源类别（禽肉 / 猪肉 / 牛肉 / 羊肉 / 鱼类 / 虾贝 / 豆制品）逐日轮换且相邻天不重复
  - 相邻两天不出现重复食材
  - 肝脏类食材全周至多 1 次
  - 全周蛋白质来源类别不少于 5 类
- **家庭采购与库存管理**：
  - 周菜单按食材自动聚合采购清单（未来需求 − 现有库存），支持家人自动均衡分工与手动认领
  - 确认到货（支持部分到货、按实际花费）后库存增加、支出实时计入周预算；含过敏原的食材默认拦截，可强制入库并持续预警
  - 期初库存 / 临时补采两种入库方式；按日确认三餐消耗，自动扣减库存、上报缺货、回写周限次并重算采购清单，支持撤销
  - 库存变化同步预算（剩余 / 预计超支预警）、过敏规避（入库拦截 + 库存预警）与后续配餐（优先消耗库存、边际采购成本受剩余预算约束、保持相邻天不重复与周限次）
- **营养可视化**：三餐卡片、热量达成度、宏量供能比条、微量营养素达标度网格、周多样性统计、采购分工与库存看板。

## 目录结构

```
nutrition_planner/
├── engine/
│   ├── foods.js          # 食材营养数据库（64 种食材 × 12 项营养素 + 价格 + 可食部 + 过敏原 + 周限次）
│   ├── requirements.js   # 膳食参考摄入量计算（画像分层 + 活动 / 目标系数）
│   ├── constraints.js    # 单日多维约束求解引擎（克重调整、同类替换、库存优先与边际采购成本）
│   ├── menu.js           # 周菜单生成器（类别轮换 + 相邻天不重复 + 周限次 + 库存续配 planRange）
│   └── shopping.js       # 家庭采购与库存（成员分工、到货入库、按日消耗、预算/过敏/续配联动、JSON 持久化）
├── web/
│   └── index.html        # 单页前端（单日配餐 / 周菜单 / 采购库存三视图）
├── tests/
│   └── run_tests.js      # 50 项自动化测试
├── server.js             # HTTP 服务与 REST API
├── start.js              # 一键启动（自动选端口 + 打开浏览器）
└── package.json
```

家庭状态默认持久化在 `data/household.json`（首次操作时自动创建，已在 `.gitignore` 中忽略）。

## 采购库存使用流程

1. 在「周菜单」页生成一周菜单，点击 **🛒 载入本周并生成采购清单**：系统按食材聚合未来 7 天需求（扣除现有库存）。
2. 在「采购库存」页添加家人，点击 **⚖ 自动均衡分工**（或在清单中逐行手动认领）。
3. 家人采购后点击 **确认到货**（可部分到货并填写实际花费）：库存增加、支出计入周预算；含规避过敏原的食材会被拦截。
4. 每天饭后点击对应星期确认消耗：库存按当日菜单扣减，缺货项即时上报，采购清单按后续菜单重算。
5. 周中可随时点击 **🔁 按库存与剩余预算续配后续菜单**：未消耗的日期会优先使用家中库存、以边际采购成本受剩余周预算约束重新求解，并保持相邻天不重复与肝脏周限次。

## API

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/system` | GET | 服务信息 |
| `/api/meta` | GET | 画像选项、过敏原集合、营养素标签等元数据 |
| `/api/foods` | GET | 食材数据库（含分类、价格、过敏原、周限次） |
| `/api/plan` | POST | 单日膳食方案求解（可传 `stock_map` 库存克重映射，输出库存抵扣后的 `purchase_cost`） |
| `/api/week` | POST | 周菜单生成（含 `weekly_purchase_cost` 采购口径成本） |
| `/api/household` | GET | 家庭采购库存总览（成员分工、采购行、库存、预算执行、缺货与预警、动态流水） |
| `/api/household/settings` | POST | 同步画像 / 每日预算 / 过敏原 / 排除项 |
| `/api/household/members` | POST | 添加家庭成员 |
| `/api/household/members/:id` | POST | 改名（`{name}`）或移除（`{action:"remove"}`） |
| `/api/household/auto-assign` | POST | 待采购项按负载自动均衡分工 |
| `/api/household/lines/assign` | POST | 单行认领 / 改派（`line_id` + `member_id`） |
| `/api/household/arrive` | POST | 确认到货（`line_id`、可选 `arrived_grams`/`cost`/`force`），过敏原默认 409 拦截 |
| `/api/household/stock-in` | POST | 期初库存 / 临时补采入库（`kind:"opening"` 不计本周支出） |
| `/api/household/week/attach` | POST | 载入周菜单并聚合采购清单（`{week, params}`） |
| `/api/household/consume` | POST | 确认某日三餐消耗，扣库存、报缺货、重算清单 |
| `/api/household/consume/undo` | POST | 撤销某日消耗，回退库存 |
| `/api/household/plan-remaining` | POST | 从首个未消耗日起按库存与剩余预算续配后续菜单 |

`/api/plan` 请求示例：

```json
{
  "profile": { "age_group": "adult_m", "activity": "moderate", "goal": "maintain" },
  "budget": 25,
  "allergens": ["乳"],
  "exclude": ["broccoli"]
}
```

响应包含 `feasible`（是否满足全部约束）、`items`（每餐每项食材的克重、食材口径费用 `cost` 与库存抵扣后的边际采购费用 `purchase_cost`）、`totals`（营养素汇总，含两种成本口径）、`ratios`（三大供能比）、`adequacy`（各营养素达标度）与 `requirement`（该画像的摄入参考值）。
